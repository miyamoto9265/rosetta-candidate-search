# 概要

大脳新皮質を中心とした神経回路網は人間の複雑な認知機能の実現を支えている。新皮質をハブとしたループ神経回路の総称とするCanonical Isocortical Loops（CILs）に関するBIF設計が完了している。CILsの一部である大脳皮質ー基底核ループ回路に関するHCD/FRGの設計が課題である。この基底核回路は、行動の習慣形成に関わることが調査で明らかになっている。また、近年のLLMの進展に伴い、BRAデータの自動評価・自動設計に期待が高まっている。

本業務で行った作業の一覧は以下の通り。

* \[作業1\] 基底核習慣形成に関するBRAデータおよびデータ論文を作成し、BRAESに投稿する  
* \[作業2\] BRA統合実現方法に関する議論を行う  
* \[作業3\] 神経科学的な専門性に基づいたHCD/FRG作成への助言を行う  
* \[作業4\] v.2-0からv.2-3へBRAデータのバージョン移行を行い、移行したデータに対する自動評価プロンプトの結果を評価する。  
* \[作業5\] BRAAIKI（AI駆動型脳参照アーキテクチャ協働構築システム）のコンセプト議論とシステム試作

## \[作業1\] 基底核習慣形成に関するBRAデータおよびデータ論文を作成し、BRAESに投稿する

　前回の業務委託までに作成した基底核習慣形成に関するBRAデータを投稿に適合したバージョンに変換し、エラー修正を行ってBRAESに投稿した。以下に投稿完了メールのスクリーンショットを添付する。  
![][image1]  
図1 投稿完了メールのスクリーンショット

　また、データ論文を作成した。データ論文本体(データ論文-宮本-2025-1125.pdf)は添付資料を参照のこと。データ論文は第３回国際全脳アーキテクチャー・ワークショップに投稿した。また、ワークショップの発表資料の第一版も作成した。発表資料(国際ワークショップ発表資料-宮本-2025-1125.pdf)の最終盤を資料として添付する。また、作成したBRAデータ(BRAデータ-宮本-2025-1125.xlsx)も添付する。  
　データ論文及び発表の内容の簡単な説明としては、目標志向型行動から習慣的行動への移行が習慣形成基底核ループにおける螺旋状接続(spiraling connection)によって担われるという仮説(Haber at. al., 2000)に基づき、BRAデータを作成した。本データベースの貢献は、本仮説における情報フローを明確に構造化した点と、コンポーネントSNR\_GABA\_Pu(Putamenに投射するSNrのGABA作動性神経細胞)が本仮説における行動移行に中心的な役割を果たす可能性があることを示したことにある。

## \[作業5\] BRAAIKI（AI駆動型脳参照アーキテクチャ協働構築システム）のコンセプト議論とシステム試作

　WholeBRAの構築に向けて、LLM自動化システムの開発はかねてより行われてきたが、近年その有効性が注目されているAgenticなLLMシステムを使用したBRA自動化システムの試作を行った。また、AgenticLLM自動化システムに関する議論の中でBRAAIKI（AI駆動型脳参照アーキテクチャ協働構築システム）というコンセプトが考案され、このBRAAIKIのコンセプト議論および定義を行った。

### BRAAIKIのコンセプトとその定義

　BRAAIKIは、BRA AI Wiki の略であり、BRAデータをWikiシステムのようにしてAI(Agentic LLM)が構築するシステムおよびそれによって構築されたBRAデータのことであると定義される。  
　BRAAIKIは、類似のシステムとしてBlackboard systemがある。Blackboard systemは、複数の知識源（AIエージェント）が共有のブラックボード（知識リポジトリ）に情報を追加・修正しながら問題を解決する協働メカニズムであり、BRAAIKIのコンセプトにおける技術的な核心である。  
　また、最近開始した関連するサービスとしてxAIが提供するAI生成型のオンライン百科事典Grokipediaがある。GrokのようなAIが百科事典を知識リポジトリとして知識を継続的に自動生成・整理する仕組みが、BRAAIKIのコンセプトに近い。  
　これらの技術的背景および先行事例から、BRAAIKIにおけるAIエージェント間の協働による効率的なBRAデータの構築と動的な更新は、WholeBRAの効率的で迅速な構築を促進すると期待される。

### BRAAIKIのシステム試作

　BRAAIKIは、先述の通りAIにおける「BRAデータ構築」とその「動的な更新」によって構成される。そこで、BRAAIKIのシステム試作として、まずAgenticなAIによるBRAデータ自動構築システムを試作した。

#### 方法

　AIコーディングツール「Cursor」を使用し、任意のフォルダに添付資料のプロンプトを「0\_main.md」として保存する。その後、CursorのAI Panelから該当ファイルをメンションし、以下のようなメッセージを送信することで、関連するファイルが自動的に作成され、擬似的なBRAデータが生成される。

メッセージ例

| @0\_main.md 添付したファイルの指示に従って、タスクを実行してください。ROI: 扁桃体TLF: 恐怖条件付けとその消去 |
| :---- |

#### 仕様

　方法セクションで示した方法を実行すると、同フォルダ内に以下のようなファイルが生成される。

| ファイル名 | 詳細 |
| :---- | :---- |
| 1\_Thinking.md | Web検索と推論を行い、ROIとTLFが整合するかどうかの判定とBRAデータ作成に向けた推論を行う。 |
| 2\_BIF.md | Web検索を使用して指定したROIにおけるBIFを構築する。 |
| 3\_UC.md | 構築したBIFから、Uniform Circuit(UC)を特定する。ここではHCDのComponentとUCは同一視されている。ここで定義されたUCはそれぞれについてInterface、 Output semantics、 Fucntionの3つの項目が作成される。Fucntionは簡便のため、単純化されたUCの機能であり、Capability、 Mechanism、 Requrementに相当する。 |
| 4\_Connection.md | BIFから、UC同士の接続が定義される。 |
| 5\_Verification.md | 1-4のファイルの論理的整合性を検査する。 |
| 6\_FinalReport.md | 最終的な技術レポートが作成される。 |
| 7\_HCD\_diagram.md | draw.ioにインポートするためのMarmeid形式データが出力される。 |

#### 結果

　この試作システムを以下の3つのROIおよびTLFで実行した。AIモデルは、Claude sonnet 4.5を使用した。

| ROI | TLF |
| ----- | ----- |
| 海馬 | 自己位置推定 |
| 扁桃体と前頭前野 | 恐怖条件付けと消去 |
| 視床 | 最も研究が進んでいる分野 |

視床のTLFとしては、LLMは視覚情報の中継機能を選択した。

#### 試作システムの最終的な評価と今後

　これらの結果を受けて、試作システムを以下のように評価した。また、以下で使用するBIF、HCDなどの用語は本システムで使用した擬似的なものである。

現在のシステムは、

* BIFをWeb検索によって自律的に作成する事ができる。  
* ConnectionやUCなど、神経科学的に明らかな破綻のないHCDを作ることができる。  
* BIFimageとして破綻のないmargmeid形式のデータを作成する事ができる。

ことがわかった。

　一方で、以下の事項は未検証または課題として残っている。

* 課題  
  * 粒度が少し荒い  
* 未検証事項  
  * BIFなどのWeb検索によって神経科学的事実から作成されたデータのハルシネーション率がどのくらいか  
  * HCDの妥当性はどのくらいか  
  * 正式なHCDとして必要な他の項目を作成できるかどうか  
  * FRGを作成することができるかどうか  
  *   
  * 粒度をコントロールできるかどうか


よって、今後に向けたアクションアイテムとしては、以下のような項目が挙げられる。

* 正式なHCDとして必要な他の項目を作成できるようにする  
  * 正式なHCDを作成したあと、審査を行いその科学的妥当性を評価する。  
* FRGを作成する  
* ハルシネーション率を検証する  
* 粒度をコントロールする

　総合して、BRAWIKIの試作システム(BRA構築)は継続する価値のあるアプローチであると考えられる。
