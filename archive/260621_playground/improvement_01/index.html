1. 方針

過去トライのレガシー（homba_alias_rules_playground.csv / ..._merged.csv）は、 低スコア入力を「最も似た HOMBA エントリ」に機械的に input→1.000 で貼り付けるもので、 解剖学的に誤ったマッピングを多数含んでいたため 削除 した。

  • 言語的に正当な関係のみ辞書化 — 綴り違い、略語、語順、真の同義語。
  • HOMBA 実在確認 — verify.py でターゲットを確認してから登録。
  • 一般化ルールを優先 — データセット固有の転記ミス（Antherior 等）は本体辞書に入れない。
  • 正しい親マッチを偽の high に昇格させない — 亜区情報の喪失を隠す旧ハックは行わない。
レガシー例（削除理由）: Middle occipital gyrus → middle frontal gyrus, Olfactory cortex → olfactory tract, Somatosensory area 1 → somatosensory radiation

  • thalamic nucleus ↔ nucleus of thalamus — 語順差を一括吸収
  • roots of the → root of — 脳神経の複数形・冠詞差
  • fascicle ↔ fasciculus、tubercule ↔ tubercle — ラテン/英・古綴り
  • caudate head/body/tail → head/body/tail of caudate nucleus — アトラス短縮表記
  • visual/auditory/somatosensory area ↔ cortex — 一次・二次感覚野の互換
  • occulomotor → oculomotor — 頻出スペルミス

4. 辞書では解決できない残課題

辞書追加による改善は round3 で頭打ち。 残る low / needs_review は HOMBA 本体・アルゴリズム・ソースデータ側の課題。

未解決 498 件を全件目視分類した詳細分析は別レポート参照: アルゴリズム/辞書改善案 （約 6 割は実質正解、改善余地は 75 件）／ HOMBA オントロジー拡張案（粒度ギャップ 116 件）。

1. HOMBA オントロジーのギャップ（最多）

該当標準名が HOMBA に存在しないため、正しい親へフォールバックするのが現状の最善。

  • HCP-MMP / Glasser2016 の微細皮質野（Prefrontal area 8Av, Parietal area PGi, Temporal area TE1a 等）
  • 齧歯類固有（barrel field, hindlimb/forelimb representation）
  • 末梢器官（Cochlea, Spiral ganglion — HOMBA は中枢のみ）
  • 個別小脳小葉（HOMBA は vermis / morphology まで）
  • カテコールアミン細胞群（A1/A4/A5 catecholaminergic cell group）

2. 正しい親マッチだが亜区が失われる

Superior/Middle/Inferior … gyrus (subdivision) → … gyrus（score 0.88）の大群。 needs_review が妥当。辞書では触らない。

3. ソースデータの転記ミス

Antherior, Mircrocellular, Vestibulochoclear, Saginum, Septimbrial, Justaparaventricular, Emminence, Leminscus 等 → rcs_species.csv / 元アトラスラベルの修正。

4. 複合・列挙ラベル

Corpus callosum and associated subcortical white matter, Reuniens-rhomboid-xiphoid Thalamus 等 → 接続詞分割・複数候補返却などアルゴリズム拡張。

5. 再現手順

本ディレクトリ（improvement_01）で実行。 rcs_eval.py は production 辞書に playground_* を連結した一時辞書で評価する。 

# 評価（production + playground 追加）
python rcs_eval.py eval --tag <tag>

# baseline（playground 追加を無視）
python rcs_eval.py eval --baseline --tag baseline

# 単一クエリ / HOMBA ターゲット確認
python rcs_eval.py search "Median raphe"
python verify.py "median raphe nucleus"

# フラグ別抽出 / ラウンド間比較
python analyze.py species_round3.csv low_confidence
python compare.py species_baseline.csv species_round3.csv

詳細な評価結果 CSV / JSON は output/ に格納。 マージ判断は本レポートのレビュー後に行う。
