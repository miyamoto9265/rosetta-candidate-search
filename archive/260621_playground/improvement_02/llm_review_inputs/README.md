# LLM Review Input Buckets

These CSV files are provisional LLM visual-review buckets for the RCS
improvement_02 experiment.

They are not an established answer dataset.  The `top_homba_id` values are the
RCS top-1 ids observed at the time of review, together with LLM review labels
such as `llm_check`, `_category`, and `_mechanism`.

Use these files to check how candidate generation changed after an RCS change.
Do not treat any row as a final reference answer without another visual review.
