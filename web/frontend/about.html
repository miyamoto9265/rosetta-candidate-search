About

このサイトについて

ROSETTA Candidate Search（RCS）は、 neuroscience 研究向けに公開している 脳領域名称の検索・照合ツールです。 フィッシング・マルウェア配布・個人情報収集を目的としたサイトではありません。

目的

論文や atlas から抽出した脳領域・解剖学的構造名（例: Pulvinar nucleus、 Left basolateral amygdala (BLA)）を入力すると、 HOMBA（Human Occipital-and-More Brain Atlas）オントロジー上の候補 ID と名称を スコア付きで返します。ROSETTA プロジェクトの候補生成エンジン（Python v0.8.0）を ブラウザから利用できる公開 UI です。

運営

  • 名称: ROSETTA Candidate Search (RCS)
  • ドメイン: rcs.mymt.site（mymt.site 配下の研究用サブドメイン）
  • ホスティング: Amazon Web Services（CloudFront + S3 + Lambda + API Gateway、リージョン ap-northeast-1）
  • ソースコード: リポジトリ内 rcs/（コア）、web/frontend/（本 UI）

お問い合わせ・セキュリティ報告

本サイトに関する問い合わせ、Safe Browsing 等の誤検知の報告、セキュリティ上の懸念は、 リポジトリ管理者（ROSETTA プロジェクト運営者）までご連絡ください。

セキュリティポリシー: /.well-known/security.txt

プライバシー・データの扱い

  • 検索フォームに入力した脳領域テキストは、候補生成のため API（AWS Lambda）に POST されます。
  • アカウント登録・ログイン機能はありません。
  • 決済・パスワード・氏名・メールアドレス等の個人情報は収集しません。
  • Cookie によるトラッキングや第三者広告は使用していません。
